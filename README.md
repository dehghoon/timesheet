# Timesheet MVP

یک تایم‌شیت کوچک برای تیم حدوداً ۱۰ نفره، با ورود نام کاربری/رمز عبور، ثبت تاریخ و ساعت شروع/پایان، شرح کار، دسترسی مدیر و خروجی CSV.

## امکانات

- ورود با نام کاربری و رمز عبور
- هر عضو فقط رکوردهای خودش را می‌بیند
- مدیر همه رکوردها را می‌بیند
- محاسبه خودکار مدت کار
- خروجی CSV برای اتصال بعدی به سیستم مالی
- رابط فارسی و واکنش‌گرا
- دیتابیس و احراز هویت با Supabase

## راه‌اندازی

1. در Supabase یک پروژه رایگان بسازید.
2. محتوای `supabase.sql` را در SQL Editor اجرا کنید.
3. در Authentication > Providers، ورود Email/Password را فعال و تأیید ایمیل را برای این اپ داخلی غیرفعال کنید.
4. برای هر عضو، در Authentication یک کاربر بسازید. ایمیل باید به شکل `username@timesheet.local` باشد؛ مثلاً `sara@timesheet.local`.
5. در `index.html` مقادیر `YOUR_SUPABASE_URL` و `YOUR_SUPABASE_ANON_KEY` را جایگزین کنید. کلید anon برای فرانت‌اند طراحی شده و امنیت داده‌ها با RLS داخل `supabase.sql` اعمال می‌شود.
6. برای مدیر کردن یک کاربر، این دستور را در SQL Editor اجرا کنید:

```sql
update public.profiles set role = 'admin' where username = 'your_admin_username';
```

7. اپ را روی GitHub Pages، Netlify یا Vercel منتشر کنید. برای GitHub Pages، Branch را روی برنچ مورد نظر و مسیر را روی `/ (root)` بگذارید.

## اتصال بعدی به Wave

در نسخه فعلی خروجی CSV فراهم شده تا گزارش ساعت‌ها قابل انتقال و پردازش باشد. مرحله بعد می‌تواند یک سرویس سمت سرور برای تبدیل گزارش‌های تأییدشده به داده‌های مالی یا فاکتور باشد؛ کلیدها و توکن‌های Wave نباید در `index.html` قرار بگیرند.

## نکته امنیتی

این اپ برای استفاده داخلی طراحی شده است. رمزها در Supabase Auth نگهداری می‌شوند و در دیتابیس اپ ذخیره نمی‌شوند. سیاست‌های Row Level Security دسترسی اعضا و مدیر را محدود می‌کنند.
